# secrets/ — where secrets live (NOT here)

Rule: no secret material ever enters git. This directory only documents the map.

| Secret | Source of truth | Injected via | Used by |
|---|---|---|---|
| Hetzner API token | Hetzner console (project `timestone`) | env `HCLOUD_TOKEN` at tofu apply | tofu hetzner |
| OVH API tokens | OVH account (IAM-restricted user) | env `OVH_*` at tofu apply | tofu ovh |
| Cloudflare API token | CF dashboard | env `CLOUDFLARE_API_TOKEN` | tofu cloudflare |
| CF tunnel token | generated by `cloudflare_tunnel` | agenix → `cloudflared-token` Secret per leg | cloudflared pods |
| k3s join token | generated at cluster init | agenix | k3s join |
| ArgoCD repo creds | GitHub fine-grained PAT (2143-Labs) | agenix → argocd-repo Secret | ArgoCD |
| DB app password | generated; CNPG managed roles | CNPG `managed.roles` | apps |
| Backup keys (home S3) | rclone config | agenix | backup cronjobs |

Do NOT create placeholder K8s Secrets in the GitOps repo — ArgoCD selfHeal will
overwrite runtime-injected values (59s lesson). Manifest references secrets by name
only.
